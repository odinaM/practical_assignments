Работа с SVG и анимацией

В этой работе я изучила векторную графику, способы её вставки на страницу, а также различные виды анимации (CSS, SMIL).

1. Базовые фигуры SVG

Нарисуйте свои фигуры или трансформируйте предложенные (прямоугольники, окружности, эллипсы).

2. Два смайлика

Нарисуйте два смайлика: один с улыбкой, второй грустный. Разместите их на одном экране.

3. Изменение цвета при наведении

Выполните изменение цвета рисунка при наведении (используется CSS hover).

4. SVG-анимация (SMIL)

Анимация свойства круга с помощью тега <animate> (движение по оси X).

5. Летающий шарик

Нарисуйте фон и шарик. При нажатии на кнопку шарик взлетает с помощью transition и transform.

6. CSS Анимация по ключевым кадрам

Анимация независимо от событий (бесконечное подпрыгивание элемента).
